## 1. Nombre

**NÁHUAT DIARIO (Edición Ruinas Ancestrales)**

Juego diario y cuaderno interactivo para aprender vocabulario del náhuatl.

## 2. Qué hace y cómo se usa

Adiviná una palabra diaria en náhuatl, con palabras de distintas longitudes y seis intentos.
Estudiá el vocabulario por tema, buscá palabras y revelá sus significados en español.
Consultá la fuente para conocer las formas y traducciones incluidas en el juego.

## 3. Enlace para abrirlo

`http://localhost:5173/`

Esta es una dirección local: solo abre el juego en la máquina donde se esté ejecutando el servidor de desarrollo. No es una URL pública de despliegue.

## 4. Cómo correrlo en otra máquina

Desde la carpeta del proyecto, ejecutá:

```sh
npm install
npm run dev
npm test
```

## 5. Qué dirigí yo y qué error encontré probando

Encontre los siguientes errores
-Error a la hora de querer ingresar una palabra no deja o dice que la palabra no es aceptada.
-Cuando borro las palabras este también se borra de las casillas donde deberia quedar.
-A consecuencia no me indica que letras son posibles o son parte de a pabra correcta.
-La app solo aceptaba 9 palabras generando los 2 errores anteriores.
